ГармоньDRIVE WEB TV — MVP DEMO

Назначение: презентационная версия веб-телевидения без обязательного backend.

Демо-вход:
  demo@webtv.local
  123456

Работает локально:
- вход / регистрация / выход;
- профиль;
- прямой эфир (симуляция плеера);
- переключение каналов;
- телепрограмма и напоминания;
- избранное;
- архив;
- редакционная студия (выбор файла без отправки);
- AI-редактор (демо-ответ).

Не подключено:
- реальный HLS/RTMP поток;
- backend / база данных;
- настоящая отправка видео;
- платежи.

Для просмотра откройте index.html.
