HARMONY DRIVE TUBE — MVP DEMO / MEDIACMS READY

Что сделано
— полностью светлая бело-синяя тема без типового тёмного видеохостинга;
— исходная горная фотография установлена главным hero-изображением;
— главная: полноэкранный hero, большие каналы, крупные видеокарточки, четыре главных сервиса;
— отдельные страницы: каталог, канал, просмотр, кабинет, профиль, студия, AI-агент, о проекте, правила;
— никаких попапов для основных сценариев;
— сохранена плоская геометрия без массовых скруглений;
— API-адаптер исправлен под подтверждённые маршруты MediaCMS: /api/v1/search, /api/v1/whoami, /api/v1/login;
— добавлен пакет backend_integration для установки поверх действующего MediaCMS, а не вместо него;
— добавлена российская security-архитектура: HTTPS/HSTS, CSRF, Secure/HttpOnly cookies, CORS, rate limits, роли, аудит, резервные копии, карантин загрузок, MIME и сигнатуры, антивирусный hook, закрытый AI Gateway.

Запуск макета
1. Откройте папку в терминале.
2. Выполните: python3 -m http.server 8080
3. Откройте: http://localhost:8080/index.html

Важно
Это frontend и интеграционный пакет. Он не заменяет действующий backend MediaCMS и не содержит рабочие секреты. Для установки на сервер используйте backend_integration/INSTALL_ON_EXISTING_MEDIACMS_RU.md. Перед публичным запуском выполните резервную копию, интеграцию в тестовой среде и юридическую проверку документов оператора персональных данных.


Демонстрационный MVP
— login.html: локальный демо-вход;
— register.html: локальная демо-регистрация;
— cabinet.html: кабинет с MVP-маркером;
— profile.html: сохранение профиля в localStorage;
— studio.html: выбор видео и имитация этапов загрузки без отправки файла;
— реальный backend и платежи в демо не подключены.
